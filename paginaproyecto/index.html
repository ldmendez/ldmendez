El problema que resolvemos

El registro de reparaciones se llevaba a mano. Los datos de clientes, equipos y diagnósticos quedaban dispersos, y responder "¿cómo va mi equipo?" tomaba tiempo.

La solución

Un prototipo web, ordenado y adaptable a celulares, que registra clientes y equipos, crea solicitudes y muestra el estado de cada reparación. Funciona con HTML, CSS y JavaScript, y guarda los datos en el navegador (LocalStorage), sin servidores.

Objetivos del proyecto

Objetivo general

Desarrollar un prototipo de sistema web que permita organizar y facilitar el seguimiento de los servicios técnicos realizados por ServiExpress Maicao S.A.S., mejorando la consulta y presentación de la información.

Objetivos específicos

  • Diseñar una interfaz web sencilla y fácil de utilizar.
  • Representar digitalmente el proceso de recepción y reparación de equipos.
  • Permitir el registro y consulta de clientes, equipos y solicitudes.
  • Implementar un sistema visual para identificar el estado de cada servicio.
  • Usar JavaScript y almacenamiento local para una demostración funcional sin servidor.

Misión y visión

Misión

Brindar servicios de diagnóstico, mantenimiento y reparación de equipos tecnológicos con honestidad, rapidez y calidad, manteniendo informado al cliente en cada etapa del proceso.

Visión
